# NodeManager — Руководство пользователя

> **NodeManager** — это веб-интерфейс для управления блокчейн-сетью. С его помощью можно отправлять транзакции, просматривать блоки, управлять аккаунтами, добывать новые блоки, хранить файлы и следить за состоянием сети — всё из обычного браузера.

## Первый запуск

Откройте браузер и перейдите по адресу вашей ноды (например, `http://localhost:8000`). Вы увидите главную страницу — раздел **«Обзор»**.

В левой части экрана расположена **боковая панель** с навигацией по разделам. В верхней части панели отображается статус ноды:

- **● В сети** — нода работает нормально
- **✖ Недоступна** — нода не отвечает (проверьте, запущен ли сервер)

Внизу боковой панели показаны две цифры:
- **Высота** — сколько блоков уже создано в цепи
- **В ожидании TX** — сколько транзакций ждут обработки

## Боковая панель

Боковая панель — это главное меню. Она всегда видна слева и содержит 8 разделов:

| Раздел | Для чего |
|--------|----------|
| 📊 **Обзор** | Общая информация о состоянии сети |
| 💳 **Транзакции** | Отправка и поиск транзакций |
| 🧱 **Блоки** | Просмотр блоков и их содержимого |
| 👤 **Аккаунты** | Просмотр аккаунтов пользователей |
| ⛏️ **Майнинг** | Добыча новых блоков |
| 📦 **IPFS** | Хранение файлов в распределённой сети |
| 🗄️ **Cassandra** | Просмотр данных в базе данных |
| 🌐 **Ноды** | Управление участниками сети |

Чтобы перейти в нужный раздел, просто нажмите на его название.

## Раздел «Обзор»

Это главная страница, которая открывается первой. Она показывает **общую картину** состояния сети.

### Карточки статистики

Вверху расположены 6 карточек с ключевыми показателями:

- **🧱 Высота цепи** — номер последнего созданного блока. Если высота 0, блоков ещё нет.
- **💳 TX в ожидании** — сколько транзакций отправлено, но ещё не записано в блок.
- **📦 Всего TX** — общее количество обработанных транзакций за всё время.
- **👤 Аккаунты** — сколько аккаунтов создано в системе.
- **🎯 Сложность** — текущая сложность добычи блоков (чем выше число, тем труднее добыть блок).
- **🔗 Нода** — статус вашей ноды («● Здорова» или «✖ Недоступна»).

### Последние блоки

Под карточками находится список последних 10 блоков. Каждый блок показывает:
- Его номер (высоту)
- Короткий хеш (уникальный идентификатор)
- Количество транзакций
- Адрес майнера, который добыл блок
- Как давно он был создан

Нажмите на любой блок, чтобы перейти к его подробностям.

### График активности

Внизу страницы — визуальный график активности за последние 20 блоков. Высота каждого столбца показывает, сколько транзакций было в соответствующем блоке.

### Обновление данных

Данные обновляются автоматически каждые 5 секунд. Чтобы обновить вручную, нажмите кнопку **«🔄 Обновить»** в правом верхнем углу.

## Раздел «Транзакции»

Транзакция — это **любое действие** в системе: отправка сообщения, создание аккаунта, обновление профиля и т.д.

### Отправка транзакции

Форма «📤 Отправить транзакцию» позволяет создать и отправить новую транзакцию:

1. **Адрес отправителя** — укажите ваш адрес (например, `0xalice`). Адрес — это просто строка, которая идентифицирует вас в системе.
2. **Адрес получателя** — укажите адрес собеседника (например, `0xbob`).
3. **Nonce** — порядковый номер вашей транзакции. Начинается с 0 и увеличивается на 1 с каждой новой транзакцией. Нажмите **«📡 Получить»**, чтобы система автоматически подставила правильное значение.
4. **Действие** — выберите тип транзакции из списка:
   - *Отправить сообщение* — просто отправить текст
   - *Создать аккаунт* — зарегистрировать новый аккаунт с именем
   - *Обновить профиль* — изменить данные аккаунта
   - *Установить «В сети»* — отметить аккаунт как онлайн
   - *Установить «Не в сети»* — отметить аккаунт как оффлайн
5. **Данные payload (JSON)** — дополнительные данные транзакции в формате JSON. При выборе действия поле заполняется автоматически.
6. **Подпись** — поле для подписи (не обязательно, система не проверяет его).
7. Нажмите **«Отправить транзакцию»**.

После отправки транзакция попадает в очередь ожидания. Чтобы она была обработана, майнер должен добыть новый блок.

### Последние транзакции

Таблица «📋 Последние транзакции» показывает 15 последних обработанных транзакций: их хеш, отправителя, получателя, действие и номер блока.

### Поиск транзакции

В блоке «🔍 Поиск транзакции» введите хеш транзакции (длинную строку из букв и цифр) и нажмите **«🔍 Найти»**. Система покажет полную информацию о транзакции.

### Транзакции по адресу

В блоке «🧾 Транзакции по адресу» введите адрес (например, `0xalice`) и нажмите **«🔍 Найти»**. Система покажет все транзакции, связанные с этим адресом (и отправленные, и полученные).

## Раздел «Блоки»

Блок — это **страница книги** блокчейна. Каждый блок содержит список транзакций и связан с предыдущим блоком, образуя цепь.

### Статистика блоков

Четыре карточки показывают:
- **Всего блоков** — общее количество блоков в цепи
- **Последняя высота** — номер самого нового блока
- **⛏️ Последний майнер** — кто добыл последний блок
- **⏱ Последний блок** — когда он был создан

### Поиск блоков

Можно найти блок двумя способами:

1. **По высоте** — введите номер блока (например, `5`) и нажмите **«Перейти»**.
2. **По хешу** — введите хеш блока (длинную строку) и нажмите **«🔍»**.

### Список блоков

Таблица показывает блоки по 15 штук. Для каждого указаны: номер, хеш, майнер, количество транзакций и время создания. Нажмите на строку или кнопку **«🔍»**, чтобы увидеть подробности.

Кнопки **«◀ Назад»** и **«Далее ▶»** позволяют листать список.

### Детали блока

При просмотре блока отображаются:
- Номер (высота) блока
- Хеш блока (уникальный идентификатор)
- Хеш предыдущего блока (ссылка на «родителя»)
- Merkle Root — сводный хеш всех транзакций блока
- State Root — хеш состояния системы после применения блока
- Время создания
- Сложность добычи
- Nonce — число, найденное майнером
- Адрес майнера
- Список транзакций в блоке

Нажмите **«✕ Закрыть»**, чтобы вернуться к списку.

## Раздел «Аккаунты»

Аккаунт — это **профиль пользователя** в системе. Каждый аккаунт имеет уникальный адрес и может хранить произвольные данные (имя, аватар и т.д.).

### Статистика

- **Всего аккаунтов** — сколько аккаунтов создано
- **🟢 В сети** — сколько аккаунтов сейчас онлайн

### Просмотр аккаунта

Введите адрес (например, `0xalice`) и нажмите **«🔍 Найти»**. Система покажет:
- Адрес аккаунта
- Nonce (сколько транзакций отправлено)
- Все данные аккаунта (имя, аватар и т.д.)

### Все аккаунты

Таблица «📋 Все аккаунты» показывает список всех аккаунтов с их адресами и значениями nonce.

## Раздел «Майнинг»

Майнинг — это **процесс добычи новых блоков**. Майнер берёт транзакции из очереди ожидания и выполняет вычисления, чтобы «запечатать» их в новый блок. Это похоже на решение математической головоломки: нужно подобрать такое число (nonce), чтобы результат вычислений начинался с определённого количества нулей.

### Статистика майнинга

- **🎯 Текущая сложность** — сколько нулей должно быть в начале результата. Чем выше — тем труднее.
- **🧱 Всего блоков добыто** — общее количество блоков в цепи.
- **💳 TX в задаче** — сколько транзакций в текущей задаче майнинга.
- **📡 Хешрейт** — скорость вычислений (хешей в секунду).

### Управление сложностью

Ползунок позволяет изменить сложность добычи (от 1 до 20). Чем выше значение, тем больше вычислений потребуется. Выберите значение и нажмите **«Установить»**.

> **Совет:** Для тестирования используйте низкую сложность (1–4). В реальной сети значения обычно выше.

### Майнинг в один клик

1. Введите **адрес майнера** — адрес, на который будет начислена награда за добычу.
2. Нажмите **«⛏️ НАЧАТЬ МАЙНИНГ»**.
3. Браузер начнёт вычисления. Вы увидите:
   - Статус процесса
   - Прогресс-бар
   - Текущий хешрейт (хешей в секунду)
   - Текущее значение nonce
4. Когда блок будет найден, появится сообщение **«✅ Блок добыт!»** с хешем нового блока.
5. Чтобы остановить майнинг, нажмите **«⏹ ОСТАНОВИТЬ»**.

> **Важно:** Майнинг выполняется в вашем браузере и использует ресурсы компьютера. Не закрывайте вкладку во время майнинга.

## Раздел «IPFS»

IPFS — это **распределённое хранилище файлов**. Файлы хранятся не на одном сервере, а распределяются между несколькими компьютерами в сети. Каждому файлу присваивается уникальный идентификатор — **CID** (Content Identifier).

### Статистика кластера

- **Пиры кластера** — сколько компьютеров участвует в хранении файлов
- **В сети** — сколько из них сейчас доступны
- **Файлы (размещения)** — сколько файлов хранится в системе
- **Статус кластера** — общее состояние (например, «🟢 2/3 в сети»)

### Пиры кластера

Таблица показывает все компьютеры (пиры), участвующие в хранении: их ID, имя, IPFS-идентификатор, адреса и статус («🟢 В сети» или «🔴 Ошибка»).

### Размещение файлов

Таблица «📂 Размещение файлов» показывает, какие файлы (CID) на каких нодах хранятся. Можно отфильтровать по CID.

Кнопки действий:
- **«🔍»** — найти и просмотреть файл
- **«🔄»** — восстановить репликацию (если файл потерял копии)

### Загрузка файла

1. Нажмите на область **«Перетащите файл сюда или нажмите для выбора»** или перетащите файл мышью.
2. Дождитесь завершения загрузки.
3. После загрузки вы увидите:
   - Имя файла
   - CID (уникальный идентификатор)
   - Размер файла
   - Статус размещения в кластере
4. Кнопка **«📋 Копировать CID»** — копирует идентификатор в буфер обмена.
5. Кнопка **«🔍 Просмотр»** — сразу переходит к просмотру файла.

### Получение файла

1. Введите **CID** файла (например, `Qm...`).
2. Нажмите **«🔍 Просмотр»** — попробует показать файл (если это изображение, оно отобразится на экране).
3. Нажмите **«⬇ Скачать»** — скачает файл на ваш компьютер.

### История загрузок

Карточка «📋 История загрузок» показывает последние 20 загруженных вами файлов (хранится в браузере). Нажмите **«🗑 Очистить»**, чтобы удалить историю.

## Раздел «Cassandra»

Cassandra — это **база данных**, в которой хранятся блоки, транзакции и информация о нодах. Этот раздел позволяет просматривать «сырые» данные.

### Просмотр таблицы

1. Выберите таблицу из выпадающего списка:
   - **blocks** — блоки
   - **transactions** — транзакции
   - **transactions_by_block** — транзакции по блокам
   - **transactions_by_from** — транзакции по отправителю
   - **transactions_by_to** — транзакции по получателю
   - **nodes** — ноды
   - **mining_locks** — блокировки майнинга
2. Укажите лимит (сколько строк показать, по умолчанию 20).
3. Нажмите **«📋 Загрузить»**.

Система покажет таблицу с данными. Длинные значения обрезаются до 80 символов.

> **Примечание:** Этот раздел предназначен для отладки. Для повседневной работы используйте другие разделы.

## Раздел «Ноды»

Нода — это **компьютер в сети**, который хранит данные и участвует в работе блокчейна.

### Статистика

- **Всего нод** — сколько компьютеров зарегистрировано
- **Активных нод** — сколько из них сейчас работают
- **Мой ID** — идентификатор вашей ноды

### Регистрация новой ноды

Чтобы добавить новый компьютер в сеть:

1. Введите **ID ноды** (например, `node-2`).
2. Введите **API-адрес** (например, `http://192.168.1.100:8000`).
3. Нажмите **«➕ Добавить ноду»**.

### Известные ноды

Таблица показывает все зарегистрированные ноды: их ID, адрес, текущую высоту цепи, когда были в сети и статус («🟢 Активна» или «🔴 Неактивна»). Ваша нода отмечена как «(это я)».

## Частые вопросы

### Что такое блокчейн?

Блокчейн — это **цепочка блоков**, в которой каждый блок содержит список транзакций и ссылку на предыдущий блок. Это делает данные неизменными: чтобы изменить старый блок, нужно пересчитать все последующие.

### Что такое транзакция?

Транзакция — это **действие**: отправка сообщения, создание аккаунта, обновление профиля. Транзакция записывается в блок и после этого считается подтверждённой.

### Что такое nonce?

Nonce — это **порядковый номер** транзакции для конкретного аккаунта. Первая транзакция имеет nonce=0, вторая — nonce=1, и так далее. Это защищает от повторной отправки одной и той же транзакции.

### Зачем нужен майнинг?

Майнинг — это процесс **подтверждения транзакций**. Майнер собирает транзакции из очереди, выполняет вычисления и создаёт новый блок. Без майнинга транзакции остаются в очереди на неопределённый срок.

### Почему мой аккаунт не найден?

Аккаунт создаётся **автоматически** при первой транзакции с его адресом. Если вы ещё не отправляли транзакцию с адресом `0xalice`, аккаунта не существует. Просто отправьте первую транзакцию — и аккаунт появится.

### Что такое CID?

CID (Content Identifier) — это **уникальный идентификатор файла** в IPFS. По нему можно найти и скачать файл. Выглядит как длинная строка, начинающаяся с `Qm...` или `bafy...`.

### Сколько времени занимает майнинг?

Зависит от **сложности** и **мощности вашего компьютера**. При сложности 1–2 блок может быть найден за секунды. При сложности 10+ — минуты или часы.

### Можно ли использовать несколько нод?

Да! Каждая нода — это отдельный компьютер в сети. Они автоматически обмениваются данными через Cassandra. Зарегистрируйте ноды в разделе «🌐 Ноды», и они начнут работать вместе.

### Кнопка «🔄 Обновить» не работает

Проверьте, что:
1. Сервер ноды запущен
2. Вы обращаетесь по правильному адресу
3. Нет ошибок в консоли браузера (F12 → Console)
